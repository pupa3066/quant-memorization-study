#   * Ampere/Ada/Hopper (RTX 30xx/40xx, A100, H100 — sm_80/86/89/90):

#     returns True but every kernel fails. cu128 (CUDA 12.8) ships sm_120. Verify with:
#       python -c "import torch; print(torch.cuda.get_arch_list())"   # must list 'sm_120'
#     (Verified working: torch 2.11.0+cu128 on an RTX 5060 Laptop, this study.)
#

#       pip install -r requirements-cuda.txt
